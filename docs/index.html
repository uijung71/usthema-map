AI 자동 리포트

직관적 시각화
복잡한 시장 데이터를 트리맵·히트맵·선형차트로 즉각 이해 가능하게 시각화합니다.
🎯
서학개미 최적화
국내 투자자가 실제 보유한 종목 기반으로 설계된, 서학개미를 위한 전용 지수입니다.
🔄
매일 자동 업데이트
